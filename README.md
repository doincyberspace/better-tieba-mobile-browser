# 百度贴吧电脑版移动自适应

> 移动端浏览器访问百度贴吧时，**默认加载电脑版网页**并**修复其窄屏布局**，让 PC 版页面在手机上真正可用。
> 
> **请勿在使用该脚本的情况下向百度贴吧官方反馈涉及 UI 的 BUG，这不由他们负责，并且可能会给作者带来麻烦！！！**

[![License: CC0-1.0](https://img.shields.io/badge/License-CC0_1.0-lightgrey.svg)](https://creativecommons.org/publicdomain/zero/1.0/deed.zh)

一个 Tampermonkey 脚本，让你的手机浏览器也可以访问电脑端的贴吧网页版。摆脱臃肿的官方客户端，用上电脑网页端实际存在的响应式设计。由 Kimi、DeepSeek 和 MiMo 编写。

---

## 功能特性

- **强制电脑版**：用 `GM_xmlhttpRequest` 覆写桌面 UA 抓取 PC 版 HTML，配合 `document-start` 占位抢占与页面上下文 UA 伪装，稳定呈现电脑版（不依赖浏览器「桌面版网站」开关）。
- **响应式修复**：注入 `width=device-width` 视口并追加少量窄屏 CSS，修复顶栏搜索框重叠、容器写死 `min-width` 导致的溢出、吸顶标题条遮挡、弹层被裁等；内容宽度由 ~318px 提升到 ~392px，手机竖屏无横向溢出。
- **会话级切换**：脚本管理器菜单里可一键「📱 切换到手机版（本会话） / 💻 切换到电脑版」，不在页面里放浮动按钮遮挡内容。
- **优雅降级**：抓取失败或校验不通过时自动回退到原始手机版页面并提示，绝不死循环。

## 安装

需要：支持扩展的安卓浏览器（Kiwi Browser、Yandex 等）+ 脚本管理器（**Tampermonkey** 或 **Violentmonkey**）。

**方式一：通过 Greasy Fork 安装**

点击[此链接](https://greasyfork.org/zh-CN/scripts/597261-%E7%99%BE%E5%BA%A6%E8%B4%B4%E5%90%A7%E7%94%B5%E8%84%91%E7%89%88%E7%A7%BB%E5%8A%A8%E8%87%AA%E9%80%82%E5%BA%94)进入 Greasy Fork，在 Greasy Fork 直接安装脚本。

**方式二：手动粘贴**

1. 在 Release 页面下载 `tieba-desktop.user.js` ；
2. 点击浏览器工具栏上的脚本管理器图标 →「添加新脚本」；
3. 删除编辑器默认内容，把 `tieba-desktop.user.js` 全文粘贴进去；
4. 保存（Ctrl+S）。

安装后访问 `https://tieba.baidu.com/` 任意页面即自动生效。

> 脚本管理器更新脚本后，**已打开的标签页仍运行旧版本**，需要关闭旧标签页、**新开标签页**访问贴吧才会加载新版本（普通刷新不够）。

## 使用

- 打开贴吧即自动进入电脑版。
- 切换回手机版：点击脚本管理器图标 → 找到本脚本 →「📱 切换到手机版（本会话）」；恢复电脑版用「💻 切换到电脑版」。切换仅对当前标签页会话生效。

## 工作原理

1. **抢占**：`document-start` 时先在页面上下文写入一个「正在加载电脑版贴吧…」占位页，避免手机版页面的前端脚本抢跑（实测手机版页偶发死循环卡死渲染线程导致白屏）。
2. **抓取**：脚本无法修改导航请求的 UA，但 `GM_xmlhttpRequest` 可以覆写请求头。用桌面 UA 重新抓取当前地址，校验返回的是 PC 版 HTML（含 `/tb/pc/` 静态资源路径）后用 `document.write` 整体替换。
3. **伪装**：向页面上下文注入 `navigator.userAgent` / `userAgentData` 伪装，防止 PC 版前端自我检测后跳回手机版；另有看门狗兜底。
4. **适配**：注入 `width=device-width` 视口与窄屏 CSS，只补站点在手机宽度下失效的部分（详见 `docs/README.md` 的实测依据）。
5. **名片**：帖子页读取移动页 `/mo/q/frsinfo` 内嵌的吧信息，渲染卡片。

## 已知限制和特性

- 依赖 `GM_xmlhttpRequest` 的 UA 覆写能力；若贴吧改为强制校验 Client Hints，此机制可能失效（会优雅降级，不会死循环）。
- 「本吧」名片的详细数据依赖移动页 `/mo/q/frsinfo` 的内嵌结构；若贴吧改版，卡片会降级为「吧名 + 头像」，点击仍可进入该吧主页。
- 贴吧改版（DOM/CSS 结构变化）可能导致响应式规则失效，核心转换机制（`/tb/pc/` 标记校验）仍有效。

## 常见问题

**Q：我把脚本复制到 Tampermonkey 管理器内，但装到手机上后完全没反应（没卡片、排版也没变）？**
多半是你复制不全，请用完整文件重新安装。推荐使用 [Greasy Fork](https://greasyfork.org/zh-CN/scripts/597261-%E7%99%BE%E5%BA%A6%E8%B4%B4%E5%90%A7%E7%94%B5%E8%84%91%E7%89%88%E7%A7%BB%E5%8A%A8%E8%87%AA%E9%80%82%E5%BA%94) 安装本脚本。

**Q：装好了、页面是电脑版，但字非常小、排版不像手机版？**
请 **关闭浏览器的「桌面版网站（Desktop site）」** 开关。本脚本本身就负责切到电脑版；浏览器再开启桌面模式会强制宽视口并整体缩放页面，反而破坏脚本的窄屏适配（脚本检测到该模式时会提示一次）。

**Q：装了却还是手机版？**
先确认是**新开标签页**（旧标签页不会加载新脚本）；再确认脚本已启用、没有被其他贴吧脚本干扰。

**Q：会修改我的账号吗？**
不会。脚本只做页面转换与只读展示，`v1.0` 不含任何关注/发帖等写操作。

**Q：为什么搜索框/某些按钮在窄屏会隐藏？**
为避免与搜索框重叠、给内容腾出宽度，窄屏下会隐藏顶栏的「下载客户端/游戏中心」等次要入口；侧边栏功能仍可在左侧抽屉菜单中找到。在未登录状态下，头像旁边的按钮是「提交建议」功能的入口。**请勿在使用该脚本的情况下向百度贴吧官方反馈涉及 UI 的 BUG，这不由他们负责，并且可能会给作者带来麻烦！！！**

**Q：更新/安装脚本之后页面加载不出来/图标没了，怎么办？**
请清除网页缓存并重启浏览器。
